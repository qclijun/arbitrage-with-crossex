# Opportunity 投资机会筛选原则

整理日期：2026-10-07。本文记录本次讨论采用的筛选方法，不固定保存账户余额、持仓或机会排名；这些数据每次决策前都须重新查询。

## 1. 筛选目标

先确认收益能够计算、当前规模有可用报价，再比较扣除成本后的收益，最后结合已有持仓、资金余量和共同风险形成推荐。

需要区分三个结果：

- **收益候选榜**：在统一假设下，哪些组合的模型净收益较好。
- **账户投资建议**：结合当前持仓和可用资金后，哪些候选值得新增、替换或续作。
- **执行可行性**：当前数量能否在容忍的滑点、协议限制和保证金条件下完成交易。候选排名不证明执行可行性。

## 2. 统一比较口径

筛选前记录以下条件，不把不同条件下的 APR 混在一起排名。

| 条件 | 本次采用的基准 | 使用规则 |
|---|---|---|
| 每腿名义本金 | $10,000 | 初步扫描基准；实际决策按目标规模重新询价 |
| Boros 入场 | 市价成交利率 | 使用该规模的盘口成交均价，不用标记利率代替可成交报价 |
| 永续入场 | 两腿市价 | 若采用 maker-hedge，单独比较成交与对冲风险 |
| 退出方式 | 到期平仓为主，滚仓为补充 | 用户明确持续滚仓时，可调整主口径 |
| 手续费 | 当前账户实际费率 | 假设 VIP 档位必须明确标注 |
| 返费 | 仅计入已验证有效且适用于两腿的返费 | 不默认所有市场或账户都有返费 |
| 已有持仓 | 先按新开完整四腿扫描，再作账户分析 | 只有可实际复用的永续腿才能省去新增入场成本 |
| 时间及账户 | 记录报价时间、账户与钱包范围 | 不跨账户复用缓存或沿用旧快照结论 |

## 3. 数据准入：缺失就是 UNKNOWN

进入可推荐候选的基本条件：

1. 两侧资产、合约、方向、到期日及抵押品关系符合该四腿策略。
2. 两侧均有匹配且可用的 CrossEx 永续合约；仅有 Boros 利差不足以构成完整机会。
3. Boros 两腿在目标规模下的盘口状态为 `ok`，固定利率可计算。
4. 所需永续盘口、费率、保证金及价格数据可用，且没有影响计算的陈旧或范围不匹配问题。
5. 净利润、总成本和资金占用均可计算。

缺失、陈旧、不完整或范围不匹配的数据标记为 **UNKNOWN**，不推断为零成本、零风险或可成交。深度不足的机会不进入该规模的推荐。

`bookStatus='ok'` 仅说明该次查询在该规模下有报价，不证明四腿必然同时成交，也不保证未来深度。扩大规模后必须重新询价。

## 4. 收益计算与初步排序

使用规模对应的成交利率计算固定利差，再扣除模型能够估算的费用。

```text
执行利差 = Boros 收固定腿成交 APR − 付固定腿成交 APR
预计净利润 = 执行利差 × 每腿名义本金 × 剩余年数 − 总成本
总成本 = Boros 交易费 + Boros 结算费 − 已验证返费
       + 永续入场手续费及滑点 + 永续退出手续费及滑点
资金净年化 = 预计净利润 ÷ 模型资金占用 ÷ 剩余年数
持有期收益率 = 预计净利润 ÷ 模型资金占用
```

Boros 盘口冲击已经反映在成交利率中，不再重复扣一次。永续退出滑点通常按当前盘口估算，不是对到期行情的保证。

初步排序规则：

1. 排除数据不满足准入条件的组合。
2. 先要求预计净利润为正，再按资金净年化从高到低排序。
3. 年化相近时，进一步比较绝对净利润、总成本、期限、目标规模的盘口和资金要求。
4. 最后结合账户约束调整推荐，允许结果为“暂不新增”。不足五个合格机会时，不强行补满 Top 5。

这是一张模型收益榜，不是经过完整风险调整的最优组合。

## 5. 不只看高 APR

同时展示剩余期限、预计净利润、总成本、模型资金占用和持有期收益率。

- **分母效应**：页面年化通常按模型最低保证金计算。加入缓冲资金后，实际资金回报率会下降。
- **短期限效应**：少量利润在短期限下年化后可能很高，但一次额外滑点就可能吃掉收益。
- **杠杆效应**：更高的允许杠杆降低模型资金占用，不代表风险更低，也不是建议按最高杠杆投入。
- **成本余量**：比较净利润与额外手续费、滑点、Gas、借款利息及换仓成本。未包含或无法确定的成本须单独说明。
- **规模效应**：当前规模的收益不能线性外推到更大规模；盘口冲击和保证金档位可能改变。

不设置未经依据验证的统一“安全 APR”或固定保证金倍数；根据账户和实际规模评估。

## 6. 到期平仓与滚仓

| 项目 | 到期平仓口径 | 滚仓口径 |
|---|---|---|
| 永续腿 | 到期关闭 | 保留并用于下一期匹配组合 |
| 本期永续退出费与滑点 | 计入 | 不计入 |
| 最终退出成本 | 本期计入模型 | 未来退出仍需考虑 |
| 资金占用 | 完整退出后释放 | 继续占用 |
| 下一期机会 | 无需依赖 | 须有匹配市场、收益及执行条件 |

年化差距被放大的原因：

```text
年化差额 ≈ 本期省去的退出成本 ÷ 模型资金占用 × 365 ÷ 剩余天数
```

滚仓能减少反复平仓、重新开仓的费用，但不保证下一期仍有同样利差。评价连续滚仓应看完整持有周期，计入最终退出成本。

用户计划到期取回资金时，采用平仓口径。计划持续经营时，对比滚仓口径，并核实下一期条件。Boros 原子滚仓、仅开新仓和原仓到期后再开仓的资金要求与风险不同，不能互相替代证明。

## 7. 结合已有持仓调整推荐

读取同一终端账户的永续持仓、Boros 持仓和可用保证金，核对方向、数量、到期日、抵押品及数据完整性。

### 新增

已有永续腿若仍在对冲未到期 Boros 仓位，不能再重复用于新增 Boros 组合。新增规模要有对应新增对冲，且两端账户都须有足够资金及缓冲。

### 续作

优先评估可延续相同资产、平台和方向的组合，目标到期日应晚于原仓。更早到期的机会不是原仓的直接续期目标。

只有原仓退出或到期后，永续腿才可能转用于下一期；复用数量应按实际匹配量确认，不能因页面有“已持有永续”标签就默认整个目标规模免费复用。

### 换仓

不能只比较新旧 APR。应在可比期限和规模下计算：

```text
换仓净增益 = 新组合预期收益 − 保留原组合的预期收益
           − 旧 Boros 平仓成本 − 永续调整成本 − 新仓成本
```

两种收益均按一致口径计算，相关成本只扣一次。已付入场费属于沉没成本，不应作为未来决策的新增费用重复计入。

若旧仓平仓报价、换腿成本或新仓报价不可验证，换仓净增益为 UNKNOWN，不用旧候选榜证明换仓划算。

## 8. 集中与分散

- 不把 Top 5 当作五份都应买入的配置清单。
- 共享平台、协议、抵押品及到期日的机会具有共同风险，多买几个名称不一定充分分散。
- 小规模账户可先选择一个较优组合，把资金留作缓冲；集中一个方案不等于投入全部资金。
- 新增资金和执行条件允许时，再考虑其他资产、平台或期限，并明确收益下降换来了哪些分散效果。
- 未平仓量只作市场规模参考，不代表当前盘口深度、退出能力或平台安全。

## 9. 推荐输出与停止条件

每次推荐至少说明：报价时间及账户范围、比较规模、入场与退出方式、组合方向及到期日、资金净年化、预计净利润、总成本、模型资金占用、推荐理由及 UNKNOWN 项。

读取已有持仓后，还应说明候选属于新增、续作还是换仓，以及可用保证金是否支持目标规模。

出现以下情况时，结论可以是“等待”或“暂不新增”：

- 完整净收益不可计算，或缺少实际规模的报价。
- 新增保证金需求超过可用资金，或缓冲不足以支持推荐。
- 所谓复用永续腿会留下未覆盖敞口。
- 换仓净增益未经验证，或额外利润不足以覆盖新增成本和执行风险。

筛选默认只读；推荐不代表授权交易，不下单、不转账、不追加保证金，也不启动有交易或通知副作用的监控程序。
