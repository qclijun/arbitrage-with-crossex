# 有 Spread 时，三腿 Spread 与普通四腿并列，由用户选择开仓路线

决策日期：2026-10-22。

1.7.x 引入 Spread 市场时定下的规则是“有 Spread 就用 Spread”：同一对场所、同一币种、抵押品和到期日存在可开仓的 Spread 时，机会页不再计算两个单独市场组成的普通四腿（即使 Spread 盘口为空），下单票据也会把选中的两个单独市场自动改到 Spread 上，只显示不提供选择。

实盘复盘表明两条路线互有胜负，不存在总是更优的一方：

- 2026-10-22 中间价：ETH 11-27 HL/GATE 普通四腿约 3.75%，Spread 约 3.53%；BTC 11-27 普通四腿约 2.96%，Spread 约 3.32%。
- 实际持仓中，Spread 的 Boros 初始保证金约为名义金额的 0.5%，普通四腿为 0.9%–1.6%；交易费折年化两者都约 0.09%–0.10%；结算费 Spread 为 0.2%，普通四腿每条 0.1%，合计相同。

现在的决定：**开仓时两条路线都计价并列出，由用户选择。**

- 机会页对同一对场所、同一到期日分别给出三腿 Spread 与普通四腿，按占用资金净 APR 统一排序，卡片标明三腿或四腿。
- 下单票据在 Pair 模式下默认仍走 Spread，用户可以显式改为两个单独市场；从机会卡片进入时按卡片路线预填，不再自动改道。
- 平仓、展期不变；停售或只能平仓的 Spread 照旧退回两个单独市场。

## Considered Options

- **保持“有 Spread 就用 Spread”**：被否。它在普通四腿利差更高时把更优路线藏起来，而且用户在机会页上无从比较。
- **自动选择收益更高的路线**：被否。两者谁更好取决于规模、可成交深度和资金约束，票据无法完整判断；在用户不知情时更换路线，也会让同一操作的结果难以解释。
- **只在 Spread 盘口为空时才显示普通四腿**：被否。只解决最极端的情况；有报价但利差更低的 Spread 照样会挡住更优路线。

## Consequences

- 同一对场所、同一到期日可能同时出现两张机会卡片。凡是按“场所对”识别机会的地方（已持有永续标签、返佣、筛选等）都必须允许两条路线并存，不得重复计数或互相覆盖。
- 默认路线不变，不主动选择的用户行为与 1.7.x 一致。
- 只读筛选脚本原本只覆盖普通四腿模型，此后会多出有 Spread 的场所对上的普通四腿候选，属于预期变化。
- 持仓侧早已支持同时持有 Spread 与两个单独市场（显示为两个 pair），本决定不需要修改持仓模型。
