## Acceptance criteria

- [x] 已有观测数据可重放生成报告，以脱敏固定样本验证分组、分母、缺失字段与结果判定，不依赖网络才能测试。
- [ ] 实际只读采集遵守已有允许频率和限流预算，不启动第二个交易引擎、不写订单、不为凑样本加速；报告明确版本、配置、路径、样本时间及限制。
- [x] 支持至少 3 组交替时段，每配置、每主要操作类别、每组至少 100 成功样本；错误/限流保留在总请求分母，冷/热不足的层不外推。
- [x] 输出 p50/p95/max、排队、资源、缺证与错误类别，以及原路径基线；无法达到样本量或排除混杂则 UNKNOWN，不伪造测量值。
- [x] 本地响应与实际暴露分开，报告支持已可验证数据的去重/数量归因及峰值、持续时间、积分；跨 venue 钟差未知不宣称精确经济暴露。
- [x] 真实基线取证是实现后的只读阶段，不是当前拆票期间执行的操作；若外部证据暂缺，工具可交付但测量里程碑保持未通过，不将整票虚报完成。
- [x] 报告判定器用固定样本验证全部池化预算：合并及至少 2/3 时段 p95 改善至少 10%，合并 p50 恶化不超过 10%，任一时段 p95 恶化不超过 max(对应基线 p95 的 10%, 20ms)；实际基线阶段不宣称尚不存在的优化已通过。
- [x] 数量不足、字段缺失、观测丢弃、跨钟误差及成交无法归因分别显式标记；工具离线通过不替代真实基线，不能因网络不可用伪造已完成测量。
