## Question

在能力和净节省证据齐备后，是否采用 Maker 展期，采用哪一条满足既定风险边界的路径，以及哪些收益、等待和异常条件决定等待、撤单或原子 Taker 回退？

## Scope

- 先判断可行性和收益规模；允许结论为保留原子 Taker，不为使用 Maker 而扩大风险。
- 用双方认可的净节省门槛与风险数值边界作决策；未知输入不得默认为零或可接受。
- 将部分成交、取消中的新增成交、unknown、到期逼近、报价变化、重启恢复等具体场景带回人工讨论。
- 此票只锁定路径与采用门槛。只有研究使细节明确后，才为状态设计、原型或验收规格新增决策票，避免提前实现。
- 必须由用户参与；代理不能替用户选择可承受的损失或等待时间。

## Completion

记录已确认选择、被排除路径、适用边界和仍需新增的决策票；在研究未解决时不认领或预先作答。

## Answer

2026-10-24：经两轮 grilling 与用户确认，采用 Maker，范围扩大为**新开仓与展期**。结构与理由见 [ADR 0003](../../../docs/adr/0003-boros-single-maker-leg-with-completion.md)，术语见 [词汇表](../../../GLOSSARY.md)「Boros 挂单」。

| # | 决定 |
|---|---|
| Q1 | 新开仓与展期都用 Maker |
| Q2 | 采用口径只计确定节省的 taker 手续费；成交价改善事后统计 |
| Q3 | 现在实施 |
| Q4 | 不做分批 IOC：当前规模下 2/4/5 ETH 成交利率相同，冲击主要是价差 |
| Q5 | Maker 腿取目标规模下买卖价差较大的一侧，deal 创建时持久化 |
| Q6 | post-only（非 SOFT_ALO）挂同侧最优价；落后 ≥2 tick 且距上次 ≥15 秒才改价 |
| Q7 | 新开仓：每确认一笔 Maker 成交立即吃单补齐，容差 0.25 个百分点，失败放宽到 0.5 再试一次，仍失败告警并隔离；补齐优先于利润 |
| Q8 | 新开仓最多等 30 分钟；撤单拿到撤净确认后剩余转吃单。展期到期前 ≤3 天停止挂单，剩余走原子吃单 |
| Q9 | 展期只挂一条新仓腿；每笔成交后其余三腿走原子 FOK 补齐 |
| Q10/Q12 | 启用门槛：一条腿预计省费 ≥ $0.5；改价上限 5 次（每笔 Boros 操作 gas 约 $0.01–0.05，按 gas 余额变化估算） |
| Q11 | 永续腿在 Boros 完成或回退完成后，按现有 `best` maker+hedge 建立 |
| Q13 | 补齐腿可成交利率比创建时变差超过 5bp，就撤掉挂单、剩余转吃单（有意偏离 ADR 0001） |
| Q14 | 正常停机先撤单并拿到撤净确认；异常退出后，重启先对账再补齐 |
| Q15 | 不足 $10 的成交先累积；deal 结束时剩下的部分记为过覆盖尾差并展示 |
| Q16 | 展期从到期前 7 天开始挂单 |
| Q17 | 展期补齐限 2 分钟内、最多 2 次；超出就停止挂单、告警、隔离 |
| Q18 | 首次实盘：约 $6k、62 天新开仓，Maker 腿只挂一次、不改价；需用户明确同意。展期使用排在其后 |

后续实施工单为 04–07。本票不构成交易或实盘授权。
