# Risk的逐数量适用契约

来源：[工单04](issues/04-ownership-and-risk.md)Q6及已确认的[策略归属契约](ownership-and-risk.md)。
[静态producer/consumer核查](evidence/risk-applicability-review.md)说明现有能力与缺口；这里规定后续实现，不宣称当前Risk已支持策略豁免。

## 只解除有证据部分的Boros覆盖要求

- 仅当浮动永续两腿切片的意图、腿身份、实际数量及对账证据有效时，其相应数量不要求Boros锁定资金费。显示“有意浮动资金费暴露”，不能伪造Boros覆盖或将真实浮动量填零。
- 不改写GLOSSARY中资金费缺口与价格净敞口的区别；解释该浮动数量为何不适用“本应有Boros却缺失”的判断，而非宣布无风险。
- 四腿/三腿Spread及其他应覆盖数量继续按真实来源、方向、单位、有效期和分配检查。Spread按实际资金费来源展开，不硬编码两单市场；原仓/抵押品/PnL仍只计一次。
- 同一Boros数量不能替多个策略重复兜底；某切片过覆盖不能掩盖另一应覆盖切片缺口。账户汇总相抵不证明每份归属都满足要求。
- 未归属、差异、来源不足、过期或scope不符不获豁免，保留原有风险/UNKNOWN；已有critical在无法验证时不能因新标签清空。认领后的当前重新计算须有相应有效证据，旧历史不回写。

## 其他风险照常

- 永续实际价格净敞口、真实单腿成交缺口/残余、账户IM/MM/清算、Boros抵押风险、执行pending/unknown/quarantine及平台/稳定币风险不因浮动策略豁免。
- 账户真实数量、权益、保证金和抵押品仍按真实账户统一评估，不把共用资金在每个切片重复当成可用余额；已被预留的执行数量不能等同实际填单。
- 不修改既有价格/保证金/清算阈值，不自动平仓、换向或新增交易。Risk反馈配合03准入，不能替代服务端费用、深度、权限和冲突门禁。
- 不能靠拆成许多小切片反复取得lot/最小美元额豁免，或以相反缺口相抵隐藏应覆盖风险；聚合门槛必须保留真实来源/数量语义，同时展示切片异常。

## producer到consumer一致性

- 必须携带并核验账户/市场/策略归属范围、单位、来源时间、完整性及适用理由；不支持的类型/币种、缺source或失效证据仍为UNKNOWN，不能为通过门禁剔除非支持资产。
- 变更的是可证明数量的适用范围。原始持仓/资金费来源事实保留；新增适用证据或指标版本须可解释，旧历史与新口径不可静默拼接。
- 将core合同/规则、实际producer、report、UI、通知与monitor逐链验证；只改前端标题、某条rule.enabled或一个producer不算完成。
- 旧普通四腿、三腿Spread、两者混合与未归属来源不得退化。旧场所/币种限定不能直接变成全市场通用接口；仍未证明的分支要明确限制。

| 当前核查分支 | 后续要求 |
|---|---|
| account默认report/UI按聚合ETH/BTC永续+Boros生成coverage | 消费已验证切片分配，逐数量解释浮动与应覆盖；账户风险真实值保留 |
| Spread已可展开两资金费来源、singles可并存 | 保留方向/单位和不重复计数，不将展开误当两个独立Boros持仓 |
| 非零HYPE令相关account producer不完整 | 补可证明的币种/单位/来源支持，或保持UNKNOWN并阻相关准入；不能宣称现状已覆盖HYPE |
| basis/rollover仍有限定ETH、特定pair/分母/watch的consumer | 逐项保留适用范围；浮动策略不套四腿锁定收益分母，未证数据保持UNKNOWN，不强行泛化 |
| Python常规监控消费同一risk/report | 与report的scope、适用理由和告警一致，不能另维护全局Boros豁免 |
| 独立ETH专用连续funding-gap历史/旧baseline链 | 显式限制/迁移；不把不支持当缺口0、不凭标签重置计时或抹历史；范围不匹配UNKNOWN |

仅在已证明该切片确无相应覆盖要求时可说明该项不适用；来源缺失/不支持不是“不适用”。没有Boros到期日的浮动切片也不能使账户其他Boros到期或抵押风险消失。

## 风险与收益分开

切片的实际收益证据不足，不产生假零费用或安全结论；预计收益为正也不豁免风险。新浮动策略不使用“锁定到期利润”等四腿特定分母来制造basis安全阈值；现有无法泛化的指标仍明确UNKNOWN/范围限制。

## 验收矩阵

| 场景 | 预期 |
|---|---|
| 已认领完整浮动两腿，无Boros | 指定数量Boros覆盖要求不适用，浮动暴露可见；价格/保证金/执行风险仍检查 |
| 两腿A满、B只部分实际成交 | 不因策略标签豁免单腿缺口，不用B reservation冒充已对冲 |
| 4.03中0.36应覆盖、3.67已确认浮动 | 0.36按真实Boros证据检查，3.67解释浮动；不整仓套标签 |
| 相同4.03但3.67未认领 | 未归属部分不获豁免，旧风险/UNKNOWN保留 |
| 某四腿过覆盖、另一四腿缺同量 | 不因账户总和相等宣告都覆盖；不可重复分配Boros |
| 普通四腿、Spread三腿及混合 | 真腿身份/方向/到期/单位可验证，无重复抵押或损益，旧风险维持 |
| Boros/归属来源缺失、过期或scope错 | UNKNOWN或保留已知危险，不以空数组/无数据推断安全 |
| HYPE或其他不支持来源 | 明确该producer缺口，不从账户总仓剔除，不假装ETH或归零 |
| 同向叠加后场外改仓、净量未变但证据缺口 | 相关归属UNKNOWN并阻新增风险，不能用总量相等自动消警 |
| 同一合成场景送report/UI/常规monitor | 适用理由和危险状态一致；独立历史链的限制可见，不清除既有连续风险 |
