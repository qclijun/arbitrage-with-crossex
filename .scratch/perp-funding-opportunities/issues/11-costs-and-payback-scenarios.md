# 规模相关成本、持有期与回本情景

Type: task
Status: open
Assignee: none
Blocked by: 01, 02, 03, 06

## Goal

06交付准入后，按[组合与成本契约](../pairs-costs-and-ranking.md)实现金额成本和回本情景；与03定义的报价证据/最终预检衔接，不改变纯历史排名，也不将情景视为实际净利润。

## Scope

- 输入用户规模/持有天数、相同标的数量的两腿名义金额、各腿窗口平均费率、maker＋hedge开仓路径、双taker情景平仓、盘口/借款/必要换汇证据。
- 经济量保持十进制字符串，分别换算到显式共同计价币，不假设稳定币1:1。成本列明来源/时间、真实或假设，区分一次性与持续项，避免盘口/滑点重复扣除。
- 真实费率缺失时可另示VIP0假设参考，但真实费用汇总UNKNOWN并交由服务端阻止下单；缺深度/必要借款或换汇也不补零。有依据的不适用成本与合法零值/返佣须保留。
- 计算每腿金额资金费、净日收入D、一次性往返成本C及H×D−C；仅输入完整时计算。D≤0无有限回本；D>0且C≤0无需回本；否则C/D；必要输入未知则UNKNOWN。
- 显式披露历史均值持续、当前盘口及未来基差/汇率风险。报价时效、规模/方向变化后的重报价及预检门禁由03提供；原型由05确定，不能用本票绕过这些决定。

## Acceptance

用离线合成证据TDD覆盖成本契约验收表，特别是UNKNOWN/零/不适用/返佣的区别、薄盘口、跨报价币缺汇率、不同两腿名义金额、持续成本吃掉正资金费差、零/负D、非正C及持有期不足。证明费用情景不改变历史主分数或放宽执行资格；类型检查、针对单文件测试、最终yarn verify及web production build，无实盘测试。
