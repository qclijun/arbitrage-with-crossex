# 当前时点认领与可证明收益归因

Type: task
Status: open
Assignee: none
Blocked by: 04, 05, 15, 16, 18

## Goal

按[归属契约](../ownership-and-risk.md)提供有证据的当前时点认领和诚实归因展示，不倒填旧仓历史。

## Scope

- 用户明确选择未归属数量及策略；以完整当前仓位、精确腿身份/方向、必要Boros证据及全部相关数量对账生成可审阅预览，展示来源、时间和剩余未归属量。既有资产页匹配仅是候选，不是长期归属证明。
- 确认写账前只读重验当前证据与占用，变化重新确认；唯一engine处理持久化认领意图，routes只写意图/wake。认领只改变已证明数量的当前归属，不发交易，也不授权新交易。
- 保存认领来源和as-of时间；不消除历史差异、不回填过去持仓/收益、不静默转移已有切片。证据不足拒绝认领；不是一键把全部旧仓标成两腿。
- 首版保证数量归属。切片资金费、手续费等金额只有逐切片现金流、实际数量及时间证据充分时显示实际归因；否则保留账户/合约汇总并将切片金额标UNKNOWN。不用当前占比、FIFO或目标量分配过去收益，不把缺费用当零或把情景当实际利润。
- 未知历史收益不单独阻止已证明数量的操作；03要求的当前真实费用/深度等准入证据仍须完整。未证明资本分母不显示权益收益率。UI细节服从05，持久化兼容服从06。

## Acceptance

离线测试选定部分旧仓认领、证据不足/过期/并发占用、剩余未归属、必要Boros不符、认领前后收益不倒填、缺逐笔时间/手续费、账户汇总可用而切片UNKNOWN；验证认领无venue mutation、不清历史差异、不绕过12准入。与15/16对账及Risk一致，使用fake clock/venue与app.inject；最终yarn verify和web production build。
