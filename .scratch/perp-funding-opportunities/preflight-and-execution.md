# 预填、确认与两腿执行契约

来源：[工单03](issues/03-preflight-and-execution.md)，2026-10-27用户两轮确认Q1—Q7；Q7选择**保留到期转taker**。
依赖[历史资格](history-and-eligibility.md)和[成本情景](pairs-costs-and-ranking.md)。本文件是待实施契约，整体[规格](spec.md)仍draft。
现有能力与缺口见[当前源码核查](evidence/preflight-review.md)，不能把以下新增要求当成已实现保障。

## 候选与意图身份

- 预填精确标的、short/long场所及合约、所选历史窗口、snapshotId/cutoff和对应资格证据；不只靠base/venue选首个symbol，不调用四腿wizard或Boros。
- 用户填写规模和两腿杠杆，显式选择maker腿；A为所选maker，B为hedge，A不固定等于short或long。不得自动取最大杠杆或以缺费率为由替用户选maker。
- 规模输入与最终标的数量、各腿杠杆、maker/hedge身份、限价、到期时间及风险确认均属于确认内容。原始与最终经济数值保持十进制字符串，不经整数美元或有效位格式化悄悄改变。
- 预览可计算规则允许的共享数量，但必须展示原始输入、最终两腿数量及取整原因；只能提交已展示且获确认的结果，不得确认后再次静默取整、clamp或改价格。
- 规模、杠杆、maker、价格、timeout或持有期/费用情景变化，立即使旧预览和长按确认失效。标的/场所/方向变化须重新选择对应历史候选并验证，不借旧行的资格。

## 预览与最终准入

- 保留800ms长按；服务端预览有效期最多10秒。以服务端签发的明确expiresAt判断，`now >= expiresAt`失效；有效期不能靠更新shownAt或重读旧数据续命。
- 长按不冻结市场。长按期间编辑、预览更新、证据失效或出现新风险提示须取消确认；临近过期开始长按，提交时已过期仍拒绝。
- 服务端绑定候选/窗口/快照及最终成交参数与证据，不能只信前端disabled或自报的“已确认”。具体凭证和存储结构由实施任务确定，不在此预设第二套执行状态机。
- 机会提交缺少上述上下文须拒绝，不能退化为无历史证据的普通pair请求。既有人工入口的兼容/迁移由06裁定，不以缺字段为绕过方式。
- 接受新执行意图时只读重验历史完整性/fresh/共同cutoff、live合约规则、白名单/同单位、两腿lot/min/max及最小金额、真实费用/盘口/必要借款换汇、余额保证金/有效杠杆/权限、当前净仓和执行冲突。
- 账户、持仓、费用与盘口在确认阶段只读刷新，保留真实来源及时间；规则按当前live版本核验。读取失败或证据过期不得用旧缓存重新盖时间，不能沿用通用预检的UNKNOWN fail-open。
- 06-Q2已由用户确认：每次预览及提交均重新只读获取必要账户/持仓、真实费用、盘口及借款/换汇证据，从该次读取开始到接受意图最多10秒，源本身亦须能证明当前有效；缺时间、源陈旧、失败或超限均阻断。首版统一严格期限，按场所放宽须另有证据及明确变更。此期限与历史15分钟/cutoff、原预览expiresAt分别约束，不因刷新当前证据延长原确认。
- 任何必要证据UNKNOWN、NaN、不置信、缺失或不满足，均明确阻断；合法已知零值与有依据的不适用成本仍按02处理。所需两腿数量不可成交或深度不足，也不能只凭顶档价格放行。
- 已确认的数量、杠杆、价格、成本或风险提示变化时，返回新预览及原因，要求再次确认；不设未获确认的价格/成本容差，不边改边下单。历史换了cutoff或所选窗口失去资格也不能沿用旧确认。
- 最后校验与接受意图的边界必须处理并发/过期，不能先验通过再无限排队接受旧报价。预检不保证场所余额被预留、未来价格不动或两腿原子成交。
- 历史排名资格与下单资格独立；无法下单的候选仍可观察并显示阻止原因。

## 仓位与冲突

- 针对所选两腿相关合约/账户检查；会先减反向旧净仓、存在未解决unknown/残余或同合约活动执行冲突时阻止新开仓。不因无关场所失败全市场停摆。
- 不能把“请求两腿方向相反”当成“相对现有账户净仓只新增风险”的证明；保证金offset也不能替代仓位用途校验。
- 04已确认：同向共享仅在所有相关切片数量/归属与账户净仓可对账时允许；按实际成交、指定切片加减，dust/未归属/场外差异不猜分配。详见[归属](ownership-and-risk.md)与[Risk适用](risk-applicability.md)。15/16未实现前不能宣称准入已满足，06仍阻塞交付。

## 风险确认与到期转taker

- 历史与当前必要证据齐备时，零/负历史差、净日收入或持有期情景非正，仍可人工预览/确认；突出警告并明确确认浮动利差/成本风险。预测盈利不作为自动阈值，人工确认不能豁免UNKNOWN等硬门槛。
- maker等待默认300秒，可选30–3600秒；范围与最终deadline须展示并绑定意图。超范围应要求修正，不能确认后静默夹值。
- 用户选择保留到期自动CONVERTING：取消/收敛maker后，按既有循环对已成交量hedge，并以A taker clips补剩余量、B继续hedge。这是初次确认授权内的同一deal，不另建补单意图。
- 首次确认必须显式授权“到期将未成交maker余量转taker”。展示正常maker A＋taker B与未成交A转taker的费用情景；尚不知届时剩余量时，注明全量A转taker的参考情景，不称成本上限。任一必要费率/成本证据未知仍阻断。
- 未取得转换授权不得提交本入口的maker单；不默认为到期停止，也不增设本票未选择的timeout-action。若未来要改变到期行为须另作决定。
- 沿用MARKET IOC，B hedge及到期转换的A均无用户价格/总成本硬上限；当前盘口和费用情景不保证实际成交。须明确确认暂时单腿敞口、价格/滑点及最终残余风险，不声称已有熔断保护。
- 不在首版新增滑点/成本熔断；若后续要求硬上限，另建任务并在完成前关闭依赖该保障的入口。当前选择不承诺该能力。

## 提交、幂等与恢复

- 区分应用意图/deal身份与引擎订单client id。候选到意图的映射须持久可查，提交前可靠建立同一身份；不能仅依赖内存modal、最多20条active列表或15分钟best-effort本地映射。
- 同一意图、相同业务内容的重复提交返回原deal及状态，不再次执行、不重置deadline；同id不同业务内容拒绝冲突，不能只返回duplicate掩盖编辑。业务内容包含候选/证据身份、最终参数、到期授权及对应确认。
- 超时或丢响应先按既有身份查询。无法确认是否已接受时保留未知并阻止另建单；只有证明未接受且旧请求已不可能迟到接受，才可另行新预览并人工创建新意图。不能把瞬时not-found当成上述证明。
- 已接受意图的查询/重复回执不因旧预览过期而变成新交易；新意图仍须通过当前全部门槛。初次接受后，页面历史刷新或关闭modal不撤销既有执行授权，也不自动换向/平仓。
- 刷新页面/跨页面按持久身份恢复同一票，包含已结束的partial/dust报告；无精确身份时提示查询，不随意认领“最新活票”。本地存储失效不能静默创建第二票。
- UI如实区分已接受、执行中、partial、dust、stopped、HALTED、unknown/quarantine；202不是成交证明，DONE也不等于满量零差。展示目标、两腿实际累计成交和残余，不能用B reserved推导B已成交。
- 页面不自动补第二笔或回滚成交；原deal仍由正常reconcile对冲已成交量。停止/暂停不能撤回成交，也不能跳过pending/quarantine冻结；未知场所状态原样显示并隔离。

## 单writer与复用边界

预览和准入只读，不改杠杆或发单。确认后路由只写意图并wake；杠杆等场所变更和订单动作须归唯一engine，每tick最多一次wire mutation。现有route直接setLeverage是待修复差异，不能沿用为新入口的例外。

复用SQLite、write-ahead订单注册/确定性client id、unknown探测及正常reconcile，不新增独立recovery状态或第二执行器。保留loopback、Host/Origin及强制API token；不扩大ETH/BTC/HYPE和同计量单位边界。

## 决策验收例子

| 输入 | 预期 |
|---|---|
| 机会含同venue多合约、用户指定maker/杠杆 | 精确两腿保留；不取首个symbol、自动最大杠杆或改maker |
| 数量需取整、两腿步长不兼容 | 展示可用最终数量并确认，或拒绝；不静默改量/靠四舍五入满足 |
| 长按中改规模/杠杆/maker/timeout | 旧预览与确认失效，重新取证和确认 |
| 预览10秒后/长按结束时过期/跨UTC整点 | 服务端拒绝旧凭证，返回新预览，不因UI尚未刷新放行 |
| 最新价格、成本或风险提示变化 | 无隐式容差，返回新预览重新确认 |
| 余额UNKNOWN、费率缺失但有VIP0、盘口不足 | 硬阻断，手工风险勾选不能豁免 |
| 同单位但lot/minimum不兼容；1000/k仅扫描可比 | 服务端按真实规则拒绝执行，不扩白名单或单位换算 |
| 相反旧净仓、相关未决残余或活动执行 | 拒绝并指出冲突；同向共享另须04规定的全部相关数量归属证明 |
| 数据齐备但情景非正 | 可人工确认，明确警告，不隐藏结果或改方向 |
| maker部分成交后到期 | 按已授权路径处理剩余A taker和B hedge；费用不能只按maker路径估 |
| 到期转换未授权/必要taker费用未知 | 不提交；不偷偷改成到期停止 |
| 双击、丢响应、同id不同payload | 同内容最多一个deal；先查询，变更内容冲突，不猜测失败重建 |
| 刷新后原票已DONE且有dust；本地存储失效 | 按原持久身份恢复真实报告，不仅靠active列表或新建一票 |
| maker部分成交+B拒单/未知、停止时成交竞态 | 现有reconcile/冻结与真实partial残余回显，页面不自动回滚/重建 |
