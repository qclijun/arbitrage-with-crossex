# 组合、成本与历史排名契约

来源：[工单02](issues/02-pairs-costs-and-ranking.md)，2026-10-27用户逐项确认Q1—Q7。
与[历史资格契约](history-and-eligibility.md)共同使用；整体[规格](spec.md)仍为draft。

## 候选身份与观察集合

- 一条候选由经济标的、short场所及精确合约、long场所及精确合约标识；枚举不同场所间所有可比较的有向组合。同场所/同合约自配不属于跨场所机会。
- 每场所恰有一个可比较合约时，n个场所形成`n × (n - 1)`个有向候选；多合约不能仅以venue名称合并，别名归一化也不能单独证明同一经济标的。
- 主排名逐组合一行，支持币种/场所过滤和分页，不用每币current max/min一对代替全量。具体页面布局和控件由05决定。
- 沿用CrossEx live观察集合，历史不足、stale和执行受限项仍可观察并有原因。主排名只纳入所选窗口双腿complete且fresh的可比较项；白名单不截断历史观察集合。
- 7/30/90/180/365天始终沿同一候选的short/long方向。7天与30天各自最优组合可能不同，不能在一行跨窗口偷换腿。

## 排名、反向和符号

- 默认30天主排名、7天对照；按所选窗口未舍入的有符号资金费差年化降序，展示舍入不参与排序。主分数不扣手续费/滑点/借款/换汇，不乘杠杆，不称权益年化或实际净利润。
- 默认保留正、零、负值及反向组合；“只看正利差”是可选过滤，不是删除观察证据。UNKNOWN不当成零排序。
- 同分按稳定的经济标的、short场所/精确合约、long场所/精确合约标识升序。相同快照和过滤条件下先全局排序再分页，不能逐页重新挑最佳组合。
- 同一窗口、相同证据下，反向资金费差是原方向的相反数；成本、可执行性和回本须分别估算，不能简单取负。
- 当前一期单列；当前反转可以提示，但不重排既定历史窗口或自动换向。两腿费率均负也须按`Σshort − Σlong`真实计算，不能固定标为“空收多付”。
- 零/负差或高APR本身都不构成下单许可；最终预检与风险确认由03/04承接，不由排名隐式裁定。

## 成本证据与UNKNOWN

成本仅在用户输入规模与持有天数后用于完整情景估算；未提供时不伪造默认规模、持有期或回本。历史率排名不依赖这些输入。独立费率信息仍可展示。

| 成本项 | 必须标明 |
|---|---|
| 开仓费用 | 已选maker＋hedge路径及每腿maker/taker角色、账户实际费率/档位、名义金额 |
| 平仓费用 | 默认两腿taker情景、对应费率及当前盘口，不能称为未来可保证成交成本 |
| 盘口/滑点 | 对应规模、买卖方向、深度/可成交均价、参考价与时间；薄盘口不得按顶档价外推全量 |
| 借款等持续成本 | 是否适用、计费币种/本金、费率及时间，按持有期计算；不适用须有依据 |
| 换汇 | 共同计价币、各腿金额转换方向、汇率及来源/时间、实际所需换汇成本 |

- 每项保留来源、时间、真实/假设标记及未知原因；经济数值为十进制字符串。开仓路径未定时不能冒充真实maker/taker成本。
- 账户费率缺失可另列VIP0假设参考，但真实费用与所需成本汇总为UNKNOWN且阻止下单，不能用假设档位取得执行资格。未知盘口、必要借款或换汇成本同样不补零。
- 不发生借款/换汇且有明确依据时相应成本可为零；“未查询到”不等于不适用。合法已知零费率或返佣也不能误标为未知。
- 每条成本按其经济含义计一次；例如已用全量可成交均价包含盘口价差/冲击时，不再重复扣同一项滑点。
- 历史排名与成本证据时效独立。历史完整但盘口太薄、费率未知时仍可排名，必须显示具体执行阻止原因；报价时效、重报价及最终门禁由03决定。
- 当前输入齐备只能支持明确假设下的估算。未来盘口、基差/价格路径、借款费率或汇率变化未被保证，不把它们假装已经对冲或计入确定收益；这些未来风险不等于当前证据可缺失。

## 不同报价稳定币与金额模型

只有经济标的同一性和资金费率计量口径已核实可比，才能进入历史排名；稳定币名称、资产别名或价格接近不能单独证明可比。执行仍限既定白名单和同计量单位，未扩大合约乘数换算支持。

金额情景先保证两腿对冲的是相同标的数量，再分别确定两腿当前名义金额，换算到场景声明的共同计价币。不能用“相同名义金额”替代数量对冲，也不能假设USDT/USDC等稳定币永远1:1。必要换汇证据缺失时金额相关结果UNKNOWN且阻止下单；已证明可比的历史百分比仍可排名。

在输入已知且单位一致时，以所选窗口各腿历史平均费率延续作恒定情景：

```text
r_short_day = Σshort已结算费率 / 窗口天数
r_long_day  = Σlong已结算费率 / 窗口天数
G_day = N_short × r_short_day - N_long × r_long_day
D = G_day - 按日持续成本
C = 开仓费用 + 情景平仓费用 + 一次性盘口/滑点及必要换汇等成本
情景持有期结果(H) = H × D - C
```

`N_short/N_long`为按相同标的数量、各腿价格和汇率分别得出的共同币名义金额；`H`为用户输入持有天数。资金费率正负均原样代入；主排名仍是纯费率差，不因两腿金额、成本或杠杆改变。费用/借款按一次性或持续性质归类，不能在C/D重复扣除。

以上是假定数量、名义金额及日费率/成本按情景保持的推演，不是历史实际现金收益重建。杠杆不简单乘主排名；若影响借款等情景成本，须反映具体成本输入。

## 回本边界

1. 必要输入或成本未知：回本为UNKNOWN，已知分项仍可展示，不按零补齐。
2. 输入齐备但`D ≤ 0`：无有限回本天数，即使历史资金费差为正，也可能被持续成本抵消。
3. `D > 0`且`C ≤ 0`：显示“无需回本”，不输出负天数；未来仍可能亏损。
4. `D > 0`且`C > 0`：简单情景回本`C / D`天。持有天数不足时可展示负情景结果，不隐去成本或改方向。

这是持有期情景，不承诺利差持续，也不覆盖未建模的基差和汇率变化损益；不称保证收益或完整实际净利润。

## 决策验收例子

| 输入 | 预期 |
|---|---|
| A/B/C每场所各一可比较合约且完整新鲜 | 同一标的有6条有向候选，不只最高/最低一对 |
| 7天最佳A/B，30天最佳C/B | 两候选分别保留，各自跨窗口不换腿 |
| 当前一期反转，30天仍正 | 当前项提示反转，30天分数及short/long不变 |
| 两腿均负，short为-0.01%、long为-0.03% | 同窗口差为+0.02%，反向为-0.02%，资金方向按符号解释 |
| 零/负分数、显示舍入后相同 | 默认保留；排序用未舍入值，真同分用稳定标识，分页不重排 |
| 账户费率缺失但有VIP0参考 | 历史排名保留，参考显式标假设；真实费用/汇总UNKNOWN并阻止下单 |
| 高APR、目标规模超盘口深度 | 不降低或隐藏历史分数；成本/可成交证据不足，显示执行阻止原因 |
| 同标的但报价稳定币不同、必要换汇未知 | 已证可比的历史百分比可排；金额/回本UNKNOWN并阻止下单，不默认1:1 |
| 已知D为0或负，包括借款超过资金费收入 | 无有限回本，不能显示负天数或将借款补零 |
| 已知D>0，C≤0 | 无需回本；真实未知费用不适用此分支 |
| N_short=110、N_long=100，日率0.001/0.0005 | G_day=0.06；不能用统一100乘费率差得到0.05代替 |
| 已知D=2、C=10、H=3，同一共同计价币 | 回本5天，3天情景结果为-4，主排名不受影响 |

实现时以离线数据验证以上例子，05决定交互原型，06锁定交付验收；本文件不表示当前产品已经实现或可交易。
