# 01: Risk 页面与 Gate 保证金、清算风险

**What to build:** 交易者能够打开沿用终端账户和刷新策略的 Risk 页面，看到 Gate 保证金、条件清算距离、数据有效性和全部启用检查的概览。其他尚未接入的数据明确显示 UNKNOWN；后续票沿用本票建立的证据、规则与展示边界。

**Blocked by:** None (can start immediately).

**Status:** done

- [x] Risk 进入现有标签导航，支持既有标签持久化、深链接、键盘访问和状态文本；账户上下文来自终端。
- [x] 交付 `gate.im_coverage`、`gate.mm_health_ratio`、`gate.liquidation_distance_pct`、`data.age_seconds` 四项检查及它们的全部关联指标。
- [x] 共用既有账户、持仓查询与清算模型；清算模型保留风险阶梯、完整敞口校验和条件假设。MM usage 与 MM health ratio 明确区分。
- [x] 从现有规则和指标契约生成启用检查列表、阈值、单位、来源和建议动作；当前全部 29 项检查可访问。尚未接入来源的检查为 UNKNOWN，并指出缺失证据。
- [x] 展示按严重度排序的概览与详情，分别统计 CRITICAL、WARNING、UNKNOWN、OK；已知严重条件不会被其他缺失指标掩盖。
- [x] 归一化证据保留适用账户、地址、支持的子账户、策略/抵押池范围、源时间、覆盖性与错误状态。既有来源的 stale/失败信号不会在复用时丢失。
- [x] 通用规则判断支持契约中的全部比较操作；边界值、无效类型/单位、缺证据、过期及未来时间得到明确结果。
- [x] 保留恢复迟滞和已知 CRITICAL 触发指标无法核验时的严重状态；页面派生状态按账户范围隔离，不改写独立监控状态。
- [x] 复用现有查询键、缓存、刷新间隔及 freshness 标志；切换到页面不启动脚本、不建立新轮询器、不全量强制重新采集。
- [x] 初次加载、首次读失败、后台失败后历史值、验证空仓与覆盖不全各有明确展示；响应时间和浏览器查询时间不冒充上游数据时间。
- [x] 凭据或钱包切换后不展示上一范围的数值或严重状态；未知账户/子账户匹配不能产生 OK。
- [x] 页面/API 模拟响应验收覆盖风险展示、账户切换、隐藏页与回到标签的请求行为、共享缓存和源失败。现有全局观察者的正常轮询保持可用。
- [x] 合成场景与现有 Python 规则结果校验边界、严重度和迟滞一致性；仅测试外部结果，不锁定内部实现。
- [x] 相关离线类型检查、页面/API 测试通过；本票范围内无下单、转账、监控状态写入、通知或通知去抖副作用。
