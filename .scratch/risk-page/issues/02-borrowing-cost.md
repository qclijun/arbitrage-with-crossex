# 02: Gate 稳定币负债与当前借款成本

**What to build:** 交易者在 Risk 中查看当前 Gate 账户的 USDT/USDC 负债和估算日利息，识别负债较高、利率缺失或成本数据不完整的情况。

**Blocked by:** 01: Risk 页面与 Gate 保证金、清算风险。

**Status:** ready-for-agent

- [ ] 接入 `gate.liability_usdt` 检查，覆盖 `gate.liability_usdt`、`gate.liability_usdc`、`gate.interest_daily_usd` 三个指标。
- [ ] 复用既有账户资产、当前利息接口及借款桶计算；共享账户缓存，避免为利息再次建立独立账户采集路径。
- [ ] 逐 venue/coin 对齐负债、借款额与利率桶；支持现有免息额度和终端成本口径，不使用另一账户或不匹配桶。
- [ ] 验证负债为零、缺失负债、负数/重复资产、缺失或无效利率及桶不一致；只有完整可验证的零负债才能得到零成本。
- [ ] 利息读失败时保留独立有效的账户数据；成本为 UNKNOWN，其他有效指标不被丢弃。
- [ ] 展示负债币种、USD/day 单位、阈值、来源和当前成本估算的限定条件；稳定币按 USD 平价估值不被当成独立脱锚报价。
- [ ] 沿用首票的账户切换、数据有效性、规则判断和刷新机制；新增必要查询也采用现有数据类的缓存/刷新规则。
- [ ] 页面和现有服务注入测试证明成本结果、异常展示、账户隔离与账户缓存复用；不新增监控或交易副作用。
- [ ] 本票可独立演示负债正常、高负债、零负债与利息来源失效四类场景，相关离线检查通过。
