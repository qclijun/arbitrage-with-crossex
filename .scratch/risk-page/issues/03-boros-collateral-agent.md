# 03: Boros ETH 抵押池与代理可用性

**What to build:** 交易者在 Risk 查看当前所选钱包的 ETH 全仓抵押池缓冲、保证金覆盖、代理授权/到期和独立 gas 余额，明确这些数据属于哪个账户与资金池。

**Blocked by:** 01: Risk 页面与 Gate 保证金、清算风险。

**Status:** ready-for-agent

- [ ] 接入 `boros.im_coverage`、`boros.mm_health_ratio`、`boros.available_eth`、`agent.approval`、`agent.gas_balance_usd` 五项检查及其全部关联指标。
- [ ] 复用既有抵押品查询、单位转换与覆盖率计算，以及既有代理状态和 gas 余额读取者/缓存；仅为未公开的必要证据补充最小只读适配。
- [ ] 使用终端选择的钱包、来源支持的子账户与 ETH 全仓池；BTC、USDT 或独立保证金池的资金不与其安全缓冲相加。
- [ ] 由既有抵押品来源校验并保留规范化资金池身份与范围，供后续结算和 ETH 策略检查复用。
- [ ] 保证金为零、无池、已验证空池、无效数值、部分持仓及失败读被分别展示；MM/IM 比值无需额外 USD 价格即可从有效抵押品数据复用。
- [ ] 代理授权只属于其配置 root/子账户；浏览另一个钱包不继承当前交易代理的 approved 状态。
- [ ] gas 与交易抵押品分开显示；缺失 gas 来源不伪装为零余额或 collateral 不足。
- [ ] 源地址或子账户不匹配时显示 UNKNOWN 和原因；切换钱包不显示旧池数据，保留上一范围状态不会污染新范围。
- [ ] 遵循既有抵押品、代理和 gas 数据类的查询/缓存政策，Risk 不重复拉取相同抵押品或另开采集器。
- [ ] 页面/API 模拟响应和必要服务测试覆盖数值/阈值、失败后的历史值、钱包与子账户切换、陌生钱包代理、部分持仓和缓存复用。
- [ ] 接口验证沿用终端认证与 Host/Origin 保护，仅提供批准的证据字段，不输出代理私钥、凭据或原始账户载荷；相关离线检查通过。
