Status: ready-for-agent
Type: task
Role: parent-tracking
Created: 2026-10-07 Asia/Taipei

## Problem

交易者无法从现有下一期报价可靠判断四笔订单的默认 Roll over 是否可执行，也无法区分深度、价格边界、交易权限、批次保证金及缺失证据。旧新共存保证金不能替代原子展期的平旧后开新模拟。

## Acceptance Criteria

- [ ] 监控明确的账户、子账户、旧/新市场、方向、到期日、数量和价格限制；切换计划隔离缓存和证据。
- [ ] 默认监控完整匹配持仓；部分计划保留未展期残余，不能将其风险清零。
- [ ] 分别验证两条旧腿平仓与两条新腿开仓权限；未知模式保持 UNKNOWN。
- [ ] 展示四笔实际方向、实际单位、可执行价格范围内的深度覆盖和数量缺口；组合取最差一笔，不混入执行路径不可用的 AMM 深度。
- [ ] 区分总深度不足、用户滑点不足与协议利率边界；展示每笔成交 APR、滑点及边界余量。
- [ ] 只读复用完整批次模拟；无模拟或字段缺失不能给出可执行或零保证金缺口结论。
- [ ] 按平旧后开新的顺序展示保证金需求和余量，避免复用 Open only 的共存保证金含义。
- [ ] 明确区分盘口容量、已模拟证明的可执行数量以及未确认的最大数量。
- [ ] 展示账户/授权/Gas 执行准备；低 Gas 且可自动补充不得误判为必然阻断。
- [ ] 保留源时间、新鲜度、完整性和原因；既有慢刷新只能产生指示性结果时不得声称实时可执行。
- [ ] 将技术就绪、经济性、到期严重程度和证据缺失分别显示；已知阻断与其他 UNKNOWN 可同时存在。
- [ ] 保留 14 天/1 天窗口及 PAUSED 语义；只有完整远期持仓证据允许暂停，已知资金费缺口仍可见。
- [ ] 不把模拟成功视为展期切换完成或展期结算完成；实际结果未确认时保持明确的不确定状态。
- [ ] 保持 Risk 只读，不执行交易、授权、Gas 补充或启动后台监控，不改变通知与去抖状态。
- [ ] 保留旧指标的语义或引入显式替代指标，相关目录/规则/UI/Python语义保持一致。
- [ ] 完成规格列出的离线 API/页面验收及必要边界测试，完成真实浏览器验收；不运行真实下单测试。
- [ ] 不扩大到成交量历史、持久订单簿采集、自动展期、Open only 全面改造及隐藏历史检查恢复。
