# 01: 恢复HL BTC/ETH跨场所方向排名

Type: task
Status: ready-for-agent
Blocked by: None (can start immediately)
Progress: resolved

**What to build:** 用户可在Directed pair rankings中看到HL原生BTC/ETH与Binance、Bybit、OKX的正反方向，包括ETH空HL、多OKX。跨计价基准的组合按同名义金额的历史资金费差年化参与观察排名，并明确标为费率差估算；排名资格与执行可行性分别判断。

- [x] 在四个场所均有同币有效合约的样本中，每币由六个扩展为十二个有向组合；无重复项，同场所不配对。只识别本次明确支持的HL原生BTC/ETH，别名、HIP-3、包装资产和不匹配单位仍明确解释原因。
- [x] 按同一窗口、共同截止点和相同名义金额计算历史资金费差年化；支持两腿结算周期不同，沿用用户已确认的数据推算周期规则，不新增严格历史文档门槛。缺期、冲突、分页及新鲜度检查保持有效，五窗口逐一判断，不把未知值当零。
- [x] API与页面可见新增方向、排序、正收益过滤、场所/币种过滤和分页；现有CEX方向的历史值及相对顺序保持正确，合法零值和负值继续显示。
- [x] 跨oracle/mark及USDC/USDT组合明确标识“费率差估算”，解释其计算口径；不显示为已经扣费的现金收益或权益收益。
- [x] 跨计价基准组合可作为历史观察候选排名；尚未统一现金流计价的组合在服务端执行预检中明确阻止开仓，不能仅凭页面有排名取得执行权限。保留独立开仓开关。
- [x] 离线回归贯通配对、读接口、页面和执行阻止原因，覆盖ETH空HL/多OKX及反向、BTC扩展、正/零/负值与局部历史失败；项目离线检查和生产构建通过。
