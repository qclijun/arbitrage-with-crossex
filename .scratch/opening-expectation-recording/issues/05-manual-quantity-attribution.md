# 05: 待关联操作的手动数量分配与审计

Type: task
Status: ready-for-agent

**What to build:** 用户可从历史找到来源不明的操作，手动关联策略和成交数量份额，并查看更改记录。

**Blocked by:** 03

实施范围：沿用规格确认的交易流程；留档不得阻止或延迟发送、对冲、补单及恢复，不改变交易准入、幂等或执行数量。采用 SQLite 系统记录和单写者约束，不新增交易调用，不记录凭证，沿用 localhost、Host/Origin 与 API token 保护。

## Acceptance criteria

- [ ] 保留待关联入口；只有唯一证据支持时自动归属，不以相近时间、共享账户仓位或当前配对比例认领。
- [ ] 支持同一执行结果的数量份额分配，拒绝超额归属；关联调整保留审计，不改原报价或成交。
- [ ] 不把账户全部永续仓位或资金费算进单笔策略；关联动作不发交易。
- [ ] 失败、已结束及历史操作均可处理，重启及备份恢复保留分配和变更记录。
- [ ] 以共享仓位、多来源与部分数量案例离线验证；展期上线后复用同一归属规则，不依赖展期功能才能交付本票。
- [ ] 本票交付相应持久化、API、界面与离线回归验证；使用单元/API/UI 测试及假交易所，不使用实盘下单验收。
