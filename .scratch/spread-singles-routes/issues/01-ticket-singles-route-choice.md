# 01: 下单票据允许选择“两个单独市场”路线

**What to build:** 在 Boros rates → Pair 中，用户选中的两个单独市场被一个可开仓的 Spread 覆盖时，“Trade on” 由只显示改为可选：默认仍为 Spread（与现状一致），也可改选“两个单独市场”。选择单独市场后，票据下两笔普通订单，估算、保证金、最大可开数量与成交回执都按两个单独市场计算，且不会被自动改回 Spread。进入票据的预填入口（含开仓向导）可以显式指定路线；未指定时行为不变。依据见 ADR 0002。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 有可开仓 Spread 时，Pair 模式提供 Spread / 两个单独市场的选择，默认 Spread；选择单独市场后提交的是两个单独市场订单。
- [ ] 选择单独市场后，切换方向、调整数量、行情刷新都不会把路线自动改回 Spread；换选市场使 Spread 不再覆盖时，选择随之失效，不残留。
- [ ] 预填可显式指定路线：指定单独市场时，开仓向导第一步直接按两个单独市场下单，回执显示“四腿”；未指定时与现状一致。
- [ ] 平仓（intent = close）的路线规则不变；停售或只能平仓的 Spread 仍自动退回单独市场，且不显示选择。
- [ ] 部分成交和补单：选择单独市场后两条腿各自部分成交，补单仍落在同两个单独市场，不会补到 Spread 上。
- [ ] 离线测试覆盖上述情况；`yarn verify` 与 `yarn --cwd web build` 通过。
