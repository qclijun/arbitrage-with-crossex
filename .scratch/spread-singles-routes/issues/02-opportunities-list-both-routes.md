# 02: 机会页同时列出三腿 Spread 与普通四腿

**What to build:** 同一对场所、同一币种/抵押品/到期日既有可开仓的 Spread、又有两个单独市场时，机会页把两条路线分别计价、分别成卡，和其他机会一起按占用资金净 APR 排序，卡片明确标出“三腿”或“四腿”。普通四腿卡片点 “Open this strategy” 时，以“两个单独市场”路线进入开仓向导并据此下单；Spread 卡片照旧走 Spread。依据见 ADR 0002。

**Blocked by:** 01（下单票据允许选择“两个单独市场”路线）

**Status:** done

- [x] 机会接口在存在可开仓 Spread 时仍返回该场所对的普通四腿，两条路线各自给出收益、费用、资金占用；停售或只能平仓的 Spread 规则不变（只给普通四腿）。
- [x] 两张卡片标识唯一、互不覆盖；展开后分别显示三条或四条腿。
- [x] 普通四腿卡片开仓后，向导第一步提交的是两个单独市场订单；Spread 卡片开仓行为与现状一致。
- [x] 按场所对识别机会的派生信息（已持有永续/展期标签、返佣、筛选、成本瀑布、分享）在两条路线并存时不重复计数、不互相覆盖。
- [x] 用现有 fixture 复现 ETH 11-27 HL/GATE：两条路线同时出现，按占用资金净 APR 排序。
- [x] 只读筛选脚本对多出的 HL/GATE 普通四腿候选给出正确结果，相应 unittest 更新并通过；`yarn verify` 与 `yarn --cwd web build` 通过。
