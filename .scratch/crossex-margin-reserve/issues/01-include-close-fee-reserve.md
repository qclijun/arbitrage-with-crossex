# 01: 修复机会页保证金遗漏平仓费预留的问题

**What to build:** 机会页按 CrossEx 的保证金规则，在两条永续腿的初始保证金中纳入预估完全平仓手续费预留，使组合总资金、资金年化和排名使用完整的模型保证金。普通四腿组合与三腿 Spread 组合、到期平仓（close）与滚仓（roll）口径统一生效。

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

**Progress:** resolved

## 背景与决策

当前模型仅使用“单腿名义价值 ÷ 杠杆”，遗漏 CrossEx 要求的平仓费保证金预留。用户已确认将修复作为一张独立、可完整验收的工单，无前置重构或其他阻塞依赖。

采用的单腿公式为：永续初始保证金 = 单腿名义价值 ÷ 杠杆 + 单腿名义价值 × 0.075%。

0.075% 是保证金计算中的预留率，不是账户实际 Maker/Taker 成交费率。它属于资金占用，不能作为一笔已付费用再次扣减预计利润；roll 省略本期永续平仓成本，也不能省略仍持有永续仓位所需的保证金预留。

规则依据：[Gate 跨所账户规则说明——合约交易的保证金要求](https://www.gate.com/zh/help/crossex/functional/49325)。实现前核对规则仍适用；如规则发生变化，记录证据并重新确认差异，不静默改变已批准的计算口径。

## 验收条件

- [x] 在负责机会定价的共享保证金计算处统一纳入 0.075% 预留；所有依赖该计算的机会组合采用一致口径，无需新增持久化数据或 API 字段。
- [x] 合成案例中，每腿名义价值均为 $15,000：40 倍腿初始保证金为 $386.25，25 倍腿为 $611.25；永续两腿合计为 $997.50，比旧模型的 $975.00 增加 $22.50。
- [x] 普通四腿组合与三腿 Spread 的 close、roll 结果均包含两条永续腿的预留；Boros 保证金沿用原有计算，组合总资金正确汇总各腿。
- [x] 机会 API、机会页资金展示、资金年化和候选排名使用修正后的组合总资金。给定相同利润和期限时，年化按新分母重算，不沿用旧分母或缓存派生值。
