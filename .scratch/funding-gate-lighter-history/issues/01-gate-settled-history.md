# 01: Gate BTC/ETH 结算历史，让 Gate 配对在 ≤180 天窗口参与排名

Type: task
Status: ready-for-agent
Blocked by: None (can start immediately)

**What to build:** 用户在 Directed pair rankings 中看到 Gate 原生 BTC/ETH（USDT 永续）与其他场所的方向组合，在 7–180 天窗口内按官方已结算历史获得排名，而不是显示 history-leg-missing。365 天窗口明确显示为不支持，而非数据缺失。

前提：Gate/Lighter 当前费率接入（BTC/ETH 合约映射、经济标的证明、mark 口径）已落地。2026-11-01 实测：Gate 公共历史接口按合约返回 `{t: 秒, r: 费率}`，8 小时一条；`from` 超过 180 天即报错，`limit` 上限 1000。

- [ ] 先证明该历史接口返回的是已结算的最终费率（不是预测值或当前值），证据级别与其余五家相同、可审；证明不成立就停下来报告，不接入。
- [ ] Gate 腿的历史可分页读取，缺期、重复、合约不匹配、分页停滞都会明确报错，不会静默接受；Gate 按合约变化的结算周期由已结算时间戳推算，不把今天的周期回填到过去。
- [ ] 7–180 天窗口的 Gate 配对可排名、可通过正收益过滤；365 天窗口给出"不支持"原因；未知值不当作零。
- [ ] 只对 BTC/ETH、临近结算时读取，不超出 Gate 公共接口限额；重启后从已保存的历史恢复。
- [ ] 离线回归覆盖正/零/负费率、局部历史失败和 365 天不支持，并覆盖与 HL（费率差估算）、与 CEX（同口径）的配对；`yarn verify` 和生产构建通过。
